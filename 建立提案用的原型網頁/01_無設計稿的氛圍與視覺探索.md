# 主題一：現有網站無設計稿，如何導入 Google Stitch 進行視覺與氛圍探索？ 🎨

當您要進行網站改版或新增活動頁面，手邊**沒有原始設計稿**（無 Figma 或 Sketch 原始檔），只有一個運作中的既有網站時，管理者面臨的最大挑戰是如何在維持品牌既有一致性的前提下，讓團隊快速討論全新的視覺定位，並快速建立點擊互動流。

本單元介紹如何利用 **Google Stitch** 作為逆向導入與發想工具，引導您先對現有網頁進行「數位化重現」與「品牌風格特徵萃取」，並在管理者、設計師與工程師之間建立高效溝通。

---

## 💡 功能導向解決方案：運用 Google Stitch 逆向導入與發想

### 步驟 A：現有網站畫面的「無痛導入與數位化重現」
可以透過以下兩種方式將現有網頁導入至 Google Stitch 的畫布中：
*   **方式一：輸入網址導入（推薦用於高精度重現）**：直接在 Google Stitch 中輸入現有網站的 URL，讓 AI 自動抓取、分析並重構該網頁的結構與視覺樣式。
*   **方式二：上傳長截圖導入（推薦用於風格探索）**：使用瀏覽器整頁長截圖功能，擷取現有網頁畫面後，直接上傳至畫布。

1. **執行數位化重現（Digital Recreation）**：
   在導入後，使用 Prompt 要求 AI 進行高精度克隆，將靜態網頁轉化為可編輯的 UI 原型：
   ```text
   請根據此網址（或截圖）的視覺排版與全部文字內容，數位化重現為可編輯的原型網頁。請儘可能原始呈現其原本的色彩配置、字體大小、按鈕與排版結構。
   ```
2. **取得高還原度可編輯基底**：Stitch 的 AI 會直接渲染出可編輯的文字、按鈕與區塊代碼。這份「數位化基底」與原網站高度一致，管理者或設計師可以直接修改文字或調整佈局，不需從零手動繪製。

### 步驟 B：在可編輯基底上進行「氛圍設計（Vibe Design）」與風格探索
1. **輸入品牌新氛圍**：在已重現的可編輯網頁基底上，向 AI 說明您的改版目標（例如：「*將此首頁改版為綠色科技風格，強調簡約、專業感與大膽的留白呼吸感*」）。
2. **AI 風格探索**：AI 會在保留原有功能架構的前提下，快速生成 3-4 套全新高保真的視覺風格提案，作為改版設計的選擇。

### 步驟 C：自動畫面串接（Stitching）
1. **定義互動路徑**：在畫布上框選按鈕並設定流向，AI 會自動根據用戶的操作行為生成邏輯上的下一頁（例如：點擊「立即加入」後，自動生成對應的表單頁）。
2. **產出互動原型**：在幾分鐘內拼湊出一個完整的點擊互動流程（User Journey），用於初期提案展示。

## 👥 與團隊的高效溝通指南

*   🗣️ **與設計師溝通（探索視覺風格與元件庫）**：
    *   **討論焦點**：不要讓設計師從零開始描摹現有網站。展示 Stitch 重現的基底與風格氛圍畫面，討論：「這樣的卡片圓角、色彩比例與留白，是否符合我們品牌的新定位？」
    *   **交付物**：Stitch 的可編輯網頁基底與視覺氛圍看板（Moodboard）。
*   🗣️ **與工程師溝通（確認動線可行性）**：
    *   **討論焦點**：展示 Stitch 串接出來的頁面流向。討論：「點擊此按鈕後，新畫面是採用覆蓋式（Overlay）彈窗，還是直接跳轉新頁面？」提早讓工程師評估技術架構。
    *   **交付物**：Stitch 互動流程圖與點擊路徑示意。

## 📖 實作範例分享

以下提供包含「上課核心實戰」在內的三個具體實作範例，展示如何將現有網站導入 Google Stitch 進行風格重現、品牌視覺提煉與活動頁探索：

### 🎓 上課實戰範例：既有品牌官網延伸 —— 探索「年度旗艦活動頁」的視覺與氛圍
*   **1. 情境設定**：
    *   **現有網站狀況**：公司已有一個運作中的品牌官方網站（以「智慧生活家電／科技品牌」為例），風格沉穩且具備既有客群。
    *   **任務目標**：行銷團隊因應下半年度推廣，需新增一個「2026 品牌年度體驗日」專屬活動頁面（Campaign Landing Page）。**這個頁面未來必須交付程式工程師開發**，但目前手邊沒有任何設計稿。管理者希望先做出高保真原型向團隊提案並驗證互動動線。
    *   **核心挑戰**：活動頁面是在既有網站的基礎上延伸，不能天馬行空胡亂設計；**必須先讓 AI 完整理解現有網站的配色、字型與風格**，在此品牌規範約束下，探索兼具活動慶典氛圍的原型。
*   **2. 實作方式（AI 導入與氛圍探索）**：
    1. **導入現有官網**：在 Google Stitch 輸入既有品牌官網網址，或上傳官網首頁長截圖。
    2. **讓 AI 學習並提取網站的配色、字型與風格**：
       使用以下 Prompt 要求 AI 先行逆向工程，提取網站的 Design Tokens 規範：
       ```text
       請深度分析此現有網站的視覺結構，提取並總結其「品牌視覺 DNA 規範」：
       1. 配色系統（Color Palette）：請提取出主色（Primary Brand Color）、輔助/強調色（Secondary/Accent Color）、背景色與文字顏色，並列出 HEX 色碼與視覺比重。
       2. 字體規範（Typography）：請辨識其標題與內文所採用的字體風格（如無襯線體、襯線體）、字重階層（Bold/Medium/Regular）與行距比例。
       3. 組件質地（UI Styling）：請分析按鈕圓角（Border Radius，例如 8px、12px 或全圓角 Pill）、卡片邊框、陰影深度（Elevation/Shadow）以及版面留白節奏。
       請將以上規範作為後續設計「全新活動頁面」時必須嚴格遵循的基底約束條件。
       ```
    3. **在既有品牌基底上，探索活動頁氛圍（Vibe Design）**：
       使用以下 Prompt 要求 AI 在既有風格內注入活動活力：
       ```text
       請在嚴格遵循上述既有網站「品牌視覺 DNA（主色系、字型階層、按鈕圓角）」的前提下，為我們設計一個全新的「2026 品牌年度體驗日」活動專屬頁面（Campaign Page）：
       - 活動氛圍定位：保留官網原本的專業俐落感，但融入「活力、探索與慶典感」的活動氛圍。
       - 視覺延伸要求：
         1. 頂部 Hero 橫幅：結合流暢的品牌幾何漸層光影，搭配醒目的活動大標題與動態倒數計時元件。
         2. 色彩運用：主體維持官網深色基調，將官網的輔助強調色（如活力琥珀橘）放大應用於活動標籤與 CTA 按鈕。
         3. 探索提案：請生成 3 套不同視覺氛圍的活動首屏提案（例如：極簡科技風、前衛潮流風、溫暖互動風）供團隊挑選。
       ```
    4. **互動串接（Stitching）**：在畫布上框選活動頁上的「立即預約體驗」按鈕，拉出連線至次級的報名表單卡片，形成可點擊的原型動線。
*   **3. 溝通與交付成效（為交給程式做準備）**：
    *   **對設計師**：提供提取出的色票與 3 套風格板，設計師無需通靈，能快速在 Figma 中定案活動主視覺。
    *   **對工程師**：提早讓工程師確認活動頁是否能完全沿用官網既有的 CSS 變數（CSS Variables），避免未來切版時產生重複樣式負擔。

### 範例一：內政部戶政司全球資訊網 —— 「輸入網址」數位化重現高還原度基底
*   **背景與痛點**：
    *   **現有網站**：[內政部戶政司全球資訊網](https://www.ris.gov.tw/)
    *   **目標**：在沒有原始設計稿的情況下，直接透過**輸入網址的方式**，在 Google Stitch 中將現有網站的複雜文字與表格版型，**儘可能原始呈現與數位化重現**，作為後續調整的基礎。
*   **Stitch 實作過程**：
    1. **輸入網址導入**：在 Google Stitch 的網址輸入欄位中直接輸入戶政司官網 URL（`https://www.ris.gov.tw/`）。
    2. **執行數位化重現**：使用還原度 Prompt 指令要求高精度重製：
       ```text
       請依據此網址的視覺結構與所有文字內容，數位化重現為可編輯的原型網頁。請儘可能原始且高精度地呈現原網站的藍綠色彩配置、雙欄式版佈局、最新消息清單與全局導覽列按鈕。不需要進行任何視覺風格改版。
       ```
    3. **取得可編輯基底**：Stitch 的 AI 會自動抓取並在畫布上渲染出一個與原網頁視覺一致、但文字與版型均可編輯的數位化基底，免去手動描摹的繁瑣過程。
*   **溝通成效**：
    *   **對設計師**：提供了一個與現有網站完全一致的數位化基底，設計師可以直接在 Stitch 或匯入 Figma 修改文字或微調按鈕，不需花費數小時重新繪製舊網頁。
    *   **對工程師**：以「高還原度的數位原型」作為討論起點，確認哪些區塊的版面位置完全保留不變，降低重製時的非必要開發。

### 範例二：國家發展委員會 (國發會) 首頁 —— 「擷取截圖」風格改版與 Vibe Design
*   **背景與痛點**：
    *   **現有網站**：[國家發展委員會](https://www.ndc.gov.tw/)
    *   **目標**：將現有網站的焦點政策與最新消息，改版為兼具國際視野、前瞻性且符合永續政策的視覺風格。
*   **Stitch 實作過程**：
    1. **導入與截圖**：擷取國發會首頁畫面，上傳至 Stitch 畫布。
    2. **數位化重現**：使用 Prompt 建立數位基底：
       ```text
       請依據此國發會首頁截圖的視覺排版與內容，數位化重現為可編輯的 UI 介面，保留其原本的深藍配色、字體階層與橫幅欄位佈局，作為改版前置的數位基底。
       ```
    3. **風格改版**：以重現的數位化網頁為基底，輸入 AI Vibe Prompt：
       ```text
       將此首頁改版為具備國際視野、前瞻性且資訊透明的政府門戶網站。主視覺採用代表永續與發展的「森林深綠」與「清晨淡綠」。上方設計大器、高對比的政策焦點輪播橫幅，下方以雙欄式版型呈現「最新政策公告」與「熱門統計數據捷徑」。卡片元素需包含輕微的懸停 (hover) 放大效果，營造開放與創新的視覺氛圍。
       ```
    4. **畫面串接**：自動產出新首頁，並將「主要統計指標」卡片串接至彈出式數據儀表板（Dashboard）頁面。
*   **溝通成效**：
    *   **對設計師**：決定採用「森林深綠與清晨淡綠」的配色，並在此氛圍圖基礎上在 Figma 中快速建立對應的政策圖卡元件庫。
    *   **對工程師**：確認了首頁右側的數據捷徑會以點擊後「彈出數據儀表板」的方式呈現，提早設計資料串接的 API 架構。
