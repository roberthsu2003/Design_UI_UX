# 主題二：針對現有一頁網頁，如何調整與優化其頁面結構和內容？ 💬

現有的單頁網頁（如活動推廣頁、服務 Landing Page）往往會面臨資訊雜亂、結構不良、文字層級混亂或行動呼籲（CTA）不明顯的問題。身為管理者，您需要精確地調整網頁版面與內容，並在設計師與工程師之間傳遞標準化的重構方向。

本單元介紹如何結合 **Claude Design** 的對話式微調功能，快速重構頁面區塊，替換真實文案，並導出符合規範的設計元素與前端程式碼。

---

## 💡 功能導向解決方案：利用 Claude Design 進行對話式重構

### 步驟 A：評估現有網頁結構與痛點
在著手修改前，管理者應結合網站架構的核心觀念，檢視該單頁的以下維度：
*   **版面佈局（Layout）**：現有版型是單欄密集堆疊，還是需要改為多欄或格狀排版？（參考：[佈局模式](../佈局模式/README.md)）
*   **立體構造（Spatial Structure）**：重點資訊展開或點擊後的空間關係是否清晰？（參考：[垂直、水平、前後的立體構造](../垂直_水平_前後的立體構造/README.md)）
*   **資訊層級（Visual Hierarchy）**：標題、內文與 CTA 按鈕是否有足夠的字級對比與留白呼吸感？

### 步驟 B：使用 Claude Design 重新設計區塊
1. **載入程式碼或截圖**：將現有頁面的 HTML 程式碼片段或長截圖上傳至 Claude Design。
2. **下達結構重構指令**：使用清晰的 Prompt 要求 AI 針對特定區塊調整排版架構、強化行動呼籲並增加呼吸感：
   ```text
   請幫我重構這個網頁的首屏（Hero Section）。
   1. 將原本擁擠的單欄垂直堆疊佈局改為平衡的「雙欄式佈局（Two-column Layout）」。
   2. 左側欄位：規劃鮮明的品牌 H1 標題、2 行簡潔的價值主張說明，以及醒目的「綠色主行動按鈕（CTA）」。
   3. 右側欄位：使用帶有 16px 圓角與細緻陰影的資訊卡片，展示服務核心預覽圖，並加入微幅懸停（hover）浮起效果。
   4. 上下留白增加至 64px，確保整體版面具備足夠的呼吸感與視覺層次。
   ```
3. **取得可互動預覽**：Claude Design 會即時渲染出更新後的 UI 預覽，並保留結構語意。

### 步驟 C：真實文案替換與細微控制
1. **填入真實文案**：直接在 Claude Design 中將範本文字（Lorem Ipsum）修改為實際業務文案，檢視真實字數長度是否會造成折行或跑版。
2. **利用控制項微調**：使用內建的調整滑桿，手動微調元素間距（Padding/Margin）、色彩對比度與字級大小，直到視覺層級達到最佳平衡。
3. **導出資源**：導出該重構區塊的 SVG 向量檔或符合語意規範的 HTML/CSS 程式碼。

## 👥 與團隊的高效溝通指南

*   🗣️ **與設計師溝通（結構定稿與設計系統對接）**：
    *   **討論焦點**：將 Claude Design 產出的高保真區塊導入 Figma。與設計師討論：「這是我用真實文案調整出來的雙欄結構與資訊階層。請幫忙納入現有的設計系統（Design System），微調間距變數並確保全站字體層級的一致性。」
    *   **交付物**：Claude Design 產出的區塊 SVG 向量檔或真實文案 HTML 原型。
*   🗣️ **與工程師溝通（前端程式碼與佈局對齊）**：
    *   **討論焦點**：展示 Claude Design 生成的組件。對工程師說：「這是調整後新結構的 HTML/CSS 語意化代碼。我們希望採用 RWD 響應式佈局，左欄與右欄在行動裝置上自動向下堆疊為單欄，請以此結構進行前端重構。」
    *   **交付物**：Claude Design 導出的 HTML/CSS 程式碼參考與斷點規範。

## 📖 實作範例分享

以下提供包含「上課核心實戰」在內的三個具體實作範例，展示如何對活動單頁進行結構重構、精準風格約束與文案微調：

### 🎓 上課實戰範例：既有品牌官網延伸 —— 精準微調「年度旗艦活動頁」的單頁結構與文案
*   **1. 情境設定**：
    *   **專案進度接續**：在主題一完成「2026 品牌年度體驗日」的視覺探索後，管理者現在需要針對此活動單頁的具體內容進行深度重構。
    *   **任務目標**：活動單頁包含「首屏 Hero 號召區」、「三大亮點特色卡片」與「早鳥報名 CTA 橫幅」。管理者需在 Claude Design 中進行排版微調、填入真實活動文案，並**直接產出乾淨且符合規範的 HTML/CSS 程式碼，未來直接交付工程師開發套版**。
    *   **核心挑戰**：為了確保這個活動單頁與既有官網完美融合，**必須向 AI 明確指定既有網站的色彩數值（HEX）、字型標準與邊框圓角**，避免 AI 自行生成脫離品牌風格的怪異樣式。
*   **2. 實作方式（風格約束與對話式重構）**：
    1. **載入活動頁初步骨架**：將在主題一探索出的活動頁 HTML 程式碼或截圖載入 Claude Design。
    2. **下達嚴格風格約束與結構重構 Prompt**：
       使用以下 Prompt，將既有官網的 Design Tokens 寫入指令中，同時重構三大核心區塊：
       ```text
       請使用 Claude Design 重構「2026 品牌年度體驗日」活動單頁的核心結構與排版：
       
       【既有品牌風格約束條件（請嚴格遵循）】
       - 配色體系：
         * 主品牌深色：#0F172A（深邃海軍藍，用於標題與重要文字）
         * 活動強調色：#F59E0B（活力琥珀橘，用於主要 CTA 按鈕與亮點標籤）
         * 頁面背景色：#F8FAFC（柔和淡灰白）
         * 卡片背景色：#FFFFFF（純白）
       - 字型與字級：
         * 中文優先：Noto Sans TC，英文數字：Inter
         * H1 大標題：36px（Bold 700），內文字級：16px（Regular 400，行高 1.6）
       - 組件質地：
         * 按鈕與卡片圓角：統一為 12px
         * 卡片邊框：1px solid #E2E8F0，搭配懸停（Hover）微幅上浮 4px 的柔和陰影

       【單頁結構重構需求】
       1. Hero 首屏（60/40 雙欄式）：
          - 左欄：主標題「2026 品牌年度體驗日：未來生活的無限可能」、2 行活動理念說明、動態「早鳥優惠倒數計時器（天/時/分/秒）」，以及一顆高對比的琥珀橘主按鈕「搶先預約席位」。
          - 右欄：展示高質感情境圖卡，外層帶 12px 圓角。
       2. 三大活動亮點（3 欄卡片佈局）：
          - 均分排列展示「未來生活展區」、「大師主題論壇」與「沉浸式工作坊」。每張卡片附帶專屬小圖示與「探索詳情」文字連結。
       3. 底部早鳥 CTA 橫幅：
          - 採用深色 #0F172A 背景的大型全寬橫幅，中央文字「限量 200 席早鳥票即將完售」，搭配「立即購票」按鈕。
       ```
    3. **替換真實文案與數值滑桿微調**：
       在 Claude Design 預覽中，將實際的講師姓名、活動日期（2026/11/15）與票價填入，並使用右側滑桿將區塊間距（Section Padding）微調至 64px，確保手機端能平滑堆疊為單欄。
    4. **導出程式碼資源**：導出語意化 HTML 結構與對應的 CSS 樣式代碼。
*   **3. 溝通與交付成效（為交給程式做準備）**：
    *   **對設計師**：展示填入真實文案後的高保真原型，確認文字行數不會破壞原本卡片高度，並直接整合進 Figma 設計稿。
    *   **對工程師**：直接交付由 Claude Design 導出的 HTML/CSS。由於所有色碼與間距皆嚴格對齊既有官網規範，工程師可以直接將 CSS 類名對接到現有的前端專案（如 Tailwind 或 SCSS 變數），省去 80% 的前端刻版時間。

### 範例一：環境部淨零綠生活宣導頁 —— 重構首屏 Hero 區塊為「雙欄式呼吸感佈局」
*   **背景與痛點**：
    *   **現有網站**：[環境部淨零綠生活資訊平台](https://greenlife.moenv.gov.tw/)
    *   **目標**：現有活動單頁首屏文字過多、單欄垂直堆疊造成視覺負擔，CTA 按鈕不明顯。希望將首屏重構為具備現代感、國際視野的雙欄平衡佈局。
*   **Claude Design 重構過程**：
    1. **載入原始代碼/截圖**：截取環境部綠生活首屏畫面或貼入 HTML 結構至 Claude Design。
    2. **下達首屏重構 Prompt**：
       ```text
       請重構此環境保護宣導網頁的首屏（Hero Section）：
       - 佈局重構：將原本文字單欄垂直堆疊的密集排版，改為現代化「50/50 雙欄對稱式佈局」。
       - 左欄規劃：
         1. 標籤：醒目的小標籤「2050 淨零轉型」。
         2. 主標題：「淨零綠生活，從生活小事做起」，字級放大至 40px，強化視覺衝擊。
         3. 內文：2 行以內的行動說明，字級 16px。
         4. 行動呼籲（CTA）：一顆高對比的森林綠按鈕「立即領取綠生活指南」，右側搭配次要幽靈按鈕「瀏覽活動地圖」。
       - 右欄規劃：放置一張以自然綠色為基調的情境圖卡，外層加上 16px 圓角與輕微的懸停（hover）微幅上浮 4px 陰影效果。
       - 間距規範：上下留白（Padding）增加為 64px，營造開闊的呼吸感。在手機螢幕上自動順暢堆疊為單欄。
       ```
    3. **替換真實文案與數值微調**：填入實際宣導標語，微調按鈕色彩為符合 WCAG AA 級對比標準的深綠色（`#1B5E20`）。
    4. **導出資源**：導出語意化 HTML/CSS 代碼交由團隊評估。
*   **溝通成效**：
    *   **對設計師**：設計師認同雙欄佈局解決了文字擁擠問題，並依據此原型直接在 Figma 中建立 Hero 區塊的 Auto-layout 元件。
    *   **對工程師**：工程師直接採用導出的 Flexbox/Grid CSS 代碼進行版面替換，大幅縮短前置排版工時。

### 範例二：市民服務大平臺申辦單頁 —— 將擁擠長表單重構為「無縫式多步驟表單」
*   **背景與痛點**：
    *   **現有網站**：[臺北市政府市民服務大平臺](https://service.gov.taipei/)
    *   **目標**：線上申辦單頁一口氣陳列了 10 多個輸入欄位，行動裝置用戶需大量滑動屏幕，填寫體驗沉重且放棄率高。目標重構為分步驟的無縫表單。
*   **Claude Design 重構過程**：
    1. **載入表單結構**：將原表單包含姓名、身分證字號、聯絡電話、申辦事項、佐證文件上傳等欄位文字載入 Claude Design。
    2. **下達多步驟表單重構 Prompt**：
       ```text
       請將這份擁擠的單頁申辦表單重構為「無縫式多步驟表單（Multi-step Form）」：
       - 步驟結構劃分：
         1. 第一步【基本資料】：申請人姓名、身分證字號、聯絡電話與 Email。
         2. 第二步【申辦內容】：選擇申辦項目分類、填寫申請事由。
         3. 第三步【附件與確認】：上傳身分證明文件（支援拖曳上傳卡片）並勾選同意條款。
       - 頂部導航指示器：設計置中的步驟條（Step Progress Bar），標示「1. 基本資料 -> 2. 申辦內容 -> 3. 確認送出」，當前步驟高亮顯示。
       - 表單視覺細節：採用置中卡片式設計，背景為純白，輸入框高度加大至 48px 以利觸控操作，聚焦（Focus）時具有藍色外光暈高亮。
       - 底部操作按鈕：提供「下一步」主按鈕與「上一步」次要按鈕，點擊時透過無縫轉場切換步驟，不重新整理網頁。
       ```
    3. **微調控制項**：利用滑桿調整輸入框的外距與字體大小，確保行動端點擊區域（Tap Target）至少達到 48x48px。
    4. **導出設計成果**：導出表單的 HTML 骨架與 CSS 動畫過渡樣式。
*   **溝通成效**：
    *   **對設計師**：設計師讚許將長表單拆解為多步驟的 UX 改良，並將此無縫步驟指示器定義為全站通用的 Form Component。
    *   **對工程師**：工程師獲得清楚的步驟切換邏輯與 HTML 結構，確認採用前端狀態管理（State）進行換頁，避免頻繁發送不必要的後端驗證請求。
